V4 architecture: this is a static HTTPS-ready web app. It reads public market data and does not place orders. When hosted on GitHub Pages or another HTTPS host, it should no longer run under the restrictive content:// origin that affected the downloaded file. TradeLens tries Binance first, then Coinbase and Kraken as public-data fallbacks. A secure server-side proxy can be added later if Binance is specifically blocked.
