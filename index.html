V4.4 architecture: this is a static HTTPS-ready web app. It reads public market data and does not place orders. When hosted on GitHub Pages or another HTTPS host, it should no longer run under the restrictive content:// origin that affected the downloaded file. TradeLens uses Binance first, Binance's public market-data endpoint as a backup, then Coinbase. Kraken remains in diagnostics only because it is not reachable from the current browser/network. The setup engine is rule-based and does not guarantee outcomes. The analysis is informational and paper-trading only.
